# 趋势综合评分系统使用指南

## 概述

趋势综合评分系统是一个多维度的股票趋势分析工具，通过整合均线系统、MACD指标、价格形态识别和成交量分析，为投资决策提供量化的评分支持。

## 评分公式

**趋势总分 = (均线分 + MACD分 + 价格形态分) × 量价确认乘数**

## 评分组成

### 1. 均线系统评分（0-4分）

- **多头排列得分（0-2分）**
  - 完美多头排列（MA5 > MA10 > MA20 > MA60）：+2分
  - 基本多头排列（MA20 > MA60）：+1分

- **关键均线支撑（0-2分）**
  - 股价在MA20上方：+1分
  - 股价在MA60上方：+1分

- **趋势强度加成（0-1分）**
  - 强趋势（趋势强度≥0.7）：+1分
  - 中等趋势（趋势强度≥0.5）：+0.5分

### 2. MACD指标评分（0-3分）

- DIF和DEA均在0轴上方：+1分
- 发生金叉：+2分
- 红柱持续（非金叉情况）：+1分

### 3. 价格形态评分（-2到+2分）

- **顶部风险（优先级1）**：-2分
  - 检测到MACD背离、RSI背离或成交量异常

- **放量突破（优先级2）**：+2分
  - 突破前期阻力位且成交量放大

- **上升通道（优先级3）**：+1分
  - 价格运行在上升通道内

- **形态不明**：0分

### 4. 量价确认乘数（0.5-1.5倍）

- 强量价配合（信号≥0.3）：1.5倍
- 中等量价配合（信号≥0.15）：1.2倍
- 弱量价配合（信号≥0.05）：1.0倍
- 量价背离（信号<0.05）：0.8倍
- 严重量价背离（信号≤-0.15）：0.5倍

## 信号判定标准

- **强烈买入**：总分 ≥ 6分
- **买入**：总分 ≥ 4分
- **观望**：总分 -2到4分
- **卖出**：总分 ≤ -2分
- **强烈卖出**：总分 ≤ -4分

## 使用方法

### 1. 基本使用

```python
from src.strategy.trend_strategy import TrendStrategy

# 创建策略实例
strategy = TrendStrategy()

# 准备数据（需包含OHLCV和技术指标）
df = prepare_your_data()

# 执行各项分析
df = strategy.moving_average_analysis(df)  # 均线分析
df = strategy.macd_signal(df)              # MACD分析
df = strategy.volume_price_confirmation(df) # 量价分析

# 计算综合评分
df = strategy.calculate_trend_score(df)

# 查看结果
print(df[['date', 'close', 'trend_total_score', 'trend_signal']].tail())
```

### 3. 自定义参数

可以在创建策略实例时传入配置字典来自定义参数：

```python
config = {
    'ma_periods': [5, 10, 20, 60],           # 均线周期
    'ma_support_threshold': 0.02,            # 支撑阈值
    'trend_strength_sensitivity': 1.0,       # 趋势强度敏感度
    'macd_fast_period': 12,                  # MACD快线周期
    'macd_slow_period': 26,                  # MACD慢线周期
    'macd_signal_period': 9,                 # MACD信号线周期
    'channel_period': 30,                    # 通道周期
    'breakout_resistance_period': 60,        # 突破阻力位周期
    'volume_threshold': 1.2                  # 成交量阈值
}

strategy = TrendStrategy(config)
```

## 注意事项

1. **数据要求**
   - 至少需要60个交易日的历史数据
   - 必须包含OHLCV（开高低收成交量）数据
   - 建议预先计算好必要的技术指标

2. **评分解读**
   - 评分越高，趋势越强劲
   - 负分表示存在风险信号
   - 量价确认乘数会放大或缩小信号强度

3. **风险提示**
   - 评分系统仅供参考，不构成投资建议
   - 应结合其他分析方法综合判断
   - 历史表现不代表未来收益

## 优化建议

1. **参数调优**
   - 根据不同市场和股票特性调整参数
   - 通过回测找到最佳参数组合

2. **信号过滤**
   - 可以增加额外的过滤条件
   - 考虑市场整体环境的影响

3. **组合使用**
   - 与其他策略组合使用
   - 实现风险分散和收益优化
